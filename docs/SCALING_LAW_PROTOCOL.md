# QM9 Scaling Law：冻结实验协议 v1

日期：2026-09-07。研究分支：`research/scaling-law-v1`。数据基线提交：`fdd0a611e486f25e5c4ccd8c148db9f5a6b782d2`。

**目标保持为发现、解释并验证 molecular-property prediction 的 scaling laws。** 原有 Morgan＋XGBoost、D-MPNN、冻结 MoLFormer＋MLP 三条主路线，以及 μ、HOMO、LUMO、G 四个性质全部保留。本协议增加可检验的函数形式、前瞻性外推、容量与预算实验、机制对照和完整投稿证据，不将课题改成普通排行榜。

机器执行定义以 `config/scaling_law_v1.json` 为准；运行顺序见 `docs/RUNBOOK.md`。配置、协议、运行手册与执行代码共同进入内容哈希。研究开始后不得为了结果更好看而覆盖同一版本。

## 1. 研究问题与拟回答的结论

| 问题 | 预先安排的证据 | 不能混淆的解释 |
|---|---|---|
| RQ1：误差如何随训练分子数 N 缩放？ | 15 个规模、10 条嵌套重复曲线、竞争函数、四个未用于拟合的大规模点 | 曲线拟合好不等于预测成立；R² 不是规模律判据 |
| RQ2：缩放指数、平台与拐点是否依赖性质和表示？ | 四性质、三主路线、完整参数区间、重复采样和表示对照 | 总路线差异不直接等于架构或预训练的因果效应 |
| RQ3：N 与可训练容量 P 如何共同影响误差？ | 神经路线四档宽度、实测参数量、N/P 留出网格和最大宽度加倍训练 | P 是可训练部分；冻结编码器没有随头宽度一起扩大 |
| RQ4：数据效率优势何时转换？ | 配对误差、观测范围内交叉区间、100k 预定比较 | 不通过不受数据约束的远距离求根制造交叉点 |
| RQ5：平台来自表示、组成、优化还是划分？ | count 指纹、8192 维计数、读出头、G 残差、训练预算、验证预算、骨架与新随机划分 | 拟合平台不自动等于不可约量子化学误差 |

研究产出可以是单段幂律、带平台幂律、可预测的分段关系、对简单幂律的系统性反证，或不同机制导致的不同缩放区间。不会预设每个模型和性质都必须得到正面的幂律结果。

## 3. 样本规模、随机性和四种评价角色

### 3.1 主划分与嵌套序列

保留原主划分：训练池 104,595、验证集 13,075、测试集 13,074。前五条训练排列保持逐 ID 一致，再补五条排列。

- N：500、750、1,000、1,500、2,000、3,000、5,000、7,500、10,000、15,000、20,000、30,000、50,000、75,000、100,000。
- 抽样种子：11、22、33、44、55、66、77、88、99、110。
- 对应训练种子：101–110，按顺序一一配对。
- 每个抽样种子只排列一次训练池，D_N 是其前 N 个 ID。各规模从头初始化训练，不从小规模模型继续训练。

这十次重复同时变化抽样与初始化；额外的 3×3 交叉种子实验才用于分解两类变异。接近训练池上限时训练子集高度重合，置信区间解释为该固定数据池和评估集合条件下的随机性，不伪装成十个独立外部数据集。

### 3.2 验证集拆分

沿原验证集既有顺序拆成三个互斥部分，不重新抽取测试集：

| 集合 | 主划分数量 | 唯一用途 |
|---|---:|---|
| V_stop | 5,000 | checkpoint 选择、早停和学习率调度 |
| V_tune | 4,000 | 预定超参数候选比较 |
| V_law | 4,075 | 小规模曲线选形、拟合与冻结外推预测 |
| T | 13,074 | 所有计划训练完成后的一次冻结模型评价 |

不得让 V_tune 兼任最终独立测试，不以 V_law 选神经网络超参数。主实验的横轴是训练样本数，不声称 N=500 等于整个研究只使用了 500 个标签；必须同时报告验证标签、调参锚点和外部预训练资源。另有固定默认配置的验证标签预算实验。

### 3.3 两层留出

分子层面：T 不参与调参、早停或主曲线选形。

规模层面：只用 N≤20,000 的 V_law 结果拟合主预测，在 30k、50k、75k、100k 模型训练前保存数值预测及哈希封存。随后检查这些规模的 V_law 误差，并检查预测是否在独立 T 上复现。不能看到 100k 误差后再决定选哪一个公式或改拟合区间。

这些是程序约束和可审计时间顺序，不是密码学隐藏。原始 QM9 标签本来就在仓库。正式研究应在运行前保存分支提交与协议快照；本仓库不会冒充已经完成了第三方平台注册。

## 4. 模型与统一训练协议

| 路线 | 输入/训练部分 | 训练与保存 |
|---|---|---|
| Morgan＋XGBoost | 原 2048 位 radius=2 二进制向量 | `hist`，平方损失，V_stop MAE 早停，保存 UBJ |
| D-MPNN | 官方 Chemprop 2.2.1 有向消息传递、已有图缓存 | 72 维原子/14 维边，端到端训练，保存 state_dict |
| MoLFormer＋MLP | 固定编码器向量，仅训练预测头 | train-only 特征标准化，ReLU/Dropout MLP |

D-MPNN 主配置对 G/G_residual 使用 sum aggregation，对 μ/HOMO/LUMO 使用 mean；G 的 mean aggregation 单独作为对照。不是无意继承 CLI 默认值。

所有可拟合变换只使用该 run 的 D_N：目标均值/标准差、MLP/Ridge 特征标准化、组成回归。保存全部变换。最终预测和 MAE/RMSE 均还原到原单位，训练历史中的标准化尺度单独标识。Ridge 采用 `mean MSE + alpha ||w||²` 的定义，sklearn 的 alpha 实际传入 `alpha × N`，避免样本数变化暗中改变正则化约定。

神经模型统一 AdamW、标准化目标 MSE、梯度裁剪 5、batch 128。最大更新数为 `max(20000, 300 × ceil(N/128))`。每 `max(ceil(N/128),50)` 次更新检查一次 V_stop；至少训练 2,000 次更新后才允许早停。默认早停耐心 20 次检查；ReduceLROnPlateau 耐心 5、倍率 0.5、最低学习率 1e-6，改进阈值 1e-5（标准化尺度）。保留验证最优权重，而非最后一步。

XGBoost 默认 4,000 棵树、早停耐心 200；具体深度、学习率和正则化从预定调参候选选出。预算加倍实验将最大更新/树数及早停耐心加倍，不改输入、数据或指标。

保存后重新加载模型生成报告预测。运行记录包含实际更新数、最佳步、停止原因、训练/验证误差、实际参数量、训练时间、设备、线程、版本和内容哈希。XGBoost/Ridge 参考实现使用 CPU；`--device cuda:0` 控制神经路线，不把它们的 CPU 时间冒充 GPU 时间。固定随机种子不等于跨 GPU 位级确定性；实现对不确定算子发出警告并保留环境信息。

## 5. 一次性调参，随后冻结

每条主路线分别为四个性质及 G_residual 调参；Morgan＋MLP 和 MoLFormer＋Ridge 为四个原始性质调参。锚点 N=1,000、20,000，专用抽样种子 501/502，初始化 1501/1502。不同 N 的正式曲线使用同一份已选参数，不在每个规模偷偷多做一轮搜索。

主路线和 Morgan＋MLP 使用 12 个固定候选，第一个为默认参数，其余由固定种子无重复抽取；Ridge 六个 alpha。搜索空间完整列在 JSON，不根据中途结果扩张。每个候选完成 2 个规模×2 个重复，以 V_tune 的平均 `log(MAE / 当前训练中位数基线MAE)` 选取；分母对同一锚点所有候选相同。并列按候选序号处理，所有候选分数保留。

调参总计 1,008 次。必须完成全部预定候选，不能将未完成/崩溃候选当作性能差而删除。硬件或程序失败先修复并保留记录，不能用失败给某模型减少搜索机会。

## 6. 解释性、容量与稳健性实验

### 6.1 表示和读出

8 个原始规模×5 个重复×四性质，分别运行：2048 维 count Morgan＋XGBoost、8192 维 count Morgan＋XGBoost、binary Morgan＋MLP、冻结 MoLFormer＋Ridge。

两条 count 路线继承对应 binary-XGBoost 已选参数，以控制预测器配置；结论是表示替换对照，不称为充分独立调优后的 count 模型最优性能。Morgan＋MLP 和 MoLFormer＋MLP 的搜索预算一致，但表示和最优头配置可能同时不同，因此不作完全隔离预训练因果效应的表述。

相同二进制指纹的有限测试集组内中位数给出该输入在该测试集上的经验 MAE 下界；它不是总体 Bayes error，更不等于所有重复都由哈希冲突引起。不因指纹相同而删掉分子。

### 6.2 G 的组成与残差

每个 D_N 独立拟合：

`G_base = b + w_H n_H + w_C n_C + w_N n_N + w_O n_O + w_F n_F`。

原子数包含隐式氢。随后以 `G - G_base` 为监督目标训练三条路线，最终 `G_pred = G_base + residual_pred`。原始 G 主实验仍然保留，残差实验覆盖完整 15×10 网格，共 450 次。

这些系数是统计组成基线，不是孤立原子热力学参考值。残差路线在最终预测时显式加入组成项，不能当作单纯数值标准化；三条残差路线使用同一组成规则。中位数和组成基线均随 run 保存，可直接审计模型是否超越组成捷径。另有 G/G_residual sum 与 mean aggregation 共 30 次。

### 6.3 容量与训练预算

D-MPNN 与 MoLFormer 预测头使用主宽度的 0.5、1、2、4 倍；1 倍复用主实验。额外宽度覆盖原 8 个规模、四性质、前三重复，共 576 次。记录实际可训练参数 P，不把“宽度翻倍”写成“参数恰好翻倍”。

预先规定联合候选 `E(N,P)=c+a(N/1000)^(-alpha)+b(P/P0)^(-beta)`。用 N≤20k、宽度≤2 的格点拟合，留出 4 倍宽度及较大的 N；报告全部留出格点误差和不能辨识的情况。这个 N/P 留出检验的分析规则预先冻结，但不冒充主 N 外推那种在大规模训练前已经封存数值预测的同等时间顺序证据。拟合参数不解释为所有神经模型的普适定律，也不混称 FLOP scaling。

三条主路线的五种任务，在 1k、20k、100k、前三重复上加倍训练，共 135 次。最大 4 倍宽度的两个神经模型另加 72 次双预算，避免最大模型训练不足被误当作容量无益。配对平均误差相对改善超过 5% 标记预算敏感；5% 是预定诊断阈值，不是通用收敛定理。该结果作为平台解释的证据，不能事后替换主曲线。

### 6.4 标签预算

在 500、1k、5k、20k、100k，比较同一默认配置使用完整 V_stop 与 `min(1000,ceil(0.2N))` 个 V_stop 标签。三模型、四性质、前三重复、两种预算，共 360 次。

这两组都使用实验前指定的默认参数，不借用 20k 调参结果再自称“只有小规模标签”。报告实际 N_train、N_stop，解释额外调参知识与模型选择成本。

### 6.5 划分与随机性

新随机划分种子 20260906/20260907，以及 label-free Murcko 骨架划分。所有无环分子的空骨架作为一个不可拆分组，保存其比例、最大组、分配表和实际集合数量。骨架划分按固定贪心规则分组，不试多个划分挑好结果；任一外层分区不足 1,000 则显式停止并要求记录协议问题，不静默改成随机划分。超出某训练池的 N 预先按池大小截断并去重，实际清单在 prepare 时冻结。

跨划分组不复用主划分 HPO 参数，因为其测试分子可能在主划分调参中出现。使用相同默认参数，并增加原 random 划分的同配置参照。四个划分×三模型×四性质×8 规模×3 重复，名义 1,152 次。比较共同的实际 N；截断点不插值成不存在的实验。

此外在 1k、20k、100k 上补齐前三抽样种子×前三初始化的 3×3 网格，主实验已有对角线复用，新增 216 次。报告两因素方差分量，负估计同时保留未截断值和非负展示值；每格只有一次运行，交互作用与剩余随机误差不能单独分离。

## 7. 规模律拟合、选择与确认

### 7.1 竞争函数

令 x=N/1000，以原单位误差 E 为对象：常数、`A x^-alpha`、`E0+A x^-alpha`、`E0+A exp(-b x)`、断点固定在 2k/5k 的连续分段幂律。分段模型含平台、幅度和两段指数，不能观察大规模结果后寻找最佳断点。未观察到断点右侧时，右侧指数暂时与左侧绑定。

采用 log-error 最小二乘；正幅度、非负平台、指数范围 [0,3]，多起点拟合。平台上界由校准误差限定；触及指数边界须标记。R²/拟合残差用于描述，不参与“已经发现规律”的单独判定。平台仅为经验项，需结合区间宽度、计数表示、组成和预算证据解释。

### 7.2 只在校准范围选形

预定 rolling-origin：≤3k 预测 5k/7.5k；≤7.5k 预测 10k/15k；≤15k 预测 20k。按这些留出点的 log-RMSE 选形。分数差在 `max(最优分数×1%,1e-6)` 内时，选参数更少的函数；再并列按配置中的固定顺序。1e-6 是数值并列容差，避免完美合成幂律因浮点尾差被分段模型抢走。

算法失败的候选记录为失败，不将非有限值写进 JSON。全校准范围的最终选定函数若数值拟合失败，停止并保留失败，不强行生成一条成功曲线。

### 7.3 相关性和不确定性

主预测做 1,000 次 crossed bootstrap：第一轴重采样整条嵌套重复轨迹，第三轴对共享 V_law 分子采用同一组重采样索引，不能把不同 N 当成独立样本。给出选定形式条件下参数区间、四个外推点的点区间及同时带；前 100 次还重新选形报告稳定性。

这些带是拟合均值的不确定性，不保证包含模型失配的 95% prediction interval。超过 5% 拟合失败标记 bootstrap 不可靠，保留点预测和失败数，但不允许通过最终预测证据判据；不会为了缩小区间删掉困难重复。极端的全失败显示结果只能作为失败诊断，不能把退化区间当成置信结论。

### 7.4 冻结后的判据

对每个 route/task 单独、完整报告四个规模。预定实用预测判据：平均相对误差≤10%，最大相对误差≤20%，相对“沿用最后校准点误差”的 persistence baseline 至少改善10%，指数不触边界，bootstrap 可靠。分别在 V_law 与独立 T 检查，两者通过才记作复现。

这些阈值是研究开始前的容忍度，不是文献公认的规模律定义。单段/带平台幂律通过，支持该条件下的经验幂律；分段函数通过，报告分段关系；常数/指数函数胜出，不能重新包装成幂律。未通过时保留完整结果，报告预测失败或证据不足，不移动 holdout 边界。

跨模型比较：预先指定 100k 的四性质三对主模型共12个比较，加三条路线 G_residual 对 raw G 共3个比较；按重复配对的精确 sign-flip 检验，15个比较合为一族 Holm 校正。显著性解释需要零假设下配对差异的对称/交换性假设，并与效应量一起报告，不把 p 值当作定律真实性证明。

交叉点：整条重复曲线重采样形成规模维度同时带；相邻两个规模同向、且之前有相反方向证据时报告观测范围内区间。没有交叉也保留。模型比较、全范围事后拟合和 N/P 诊断，不替代已经冻结的主 N 外推检验。

## 9. 完成门槛、异常与投稿路径

软件门槛：固定依赖、LFS真实数组、输入/数据/划分哈希、ID对齐、互斥/嵌套、官方Chemprop前后向、所有checkpoint保存重载均通过。当前仓库的本地合成测试不是这些正式数据检查的替代品。

实验门槛：全部清单训练成功并具备匹配哈希；HPO和预测先后封存；全套非HPO模型才可评价T。失败不是低分，不能按“结果不好”剔除。未完成套件应标记 incomplete，不能用 publication_audit 的表格存在冒充已经达到投稿标准。

分析门槛：每个主单元公开10次结果；保留所有候选、外推误差、区间、失败、原单位预测和停止原因。预算敏感时不将平台归因于信息极限；跨划分结论使用同默认配置参照；负面结果保留。

稿件路径预先安排：若单段规律成立，重点呈现前瞻外推和数据/容量效率；若分段或性质依赖明显，呈现机制与适用区间；若简单规律失败，呈现系统性失配、不可辨识与对照证据。三种路径用同一套实验，不以测试结果为由重新挑公式。文章能否被接收取决于证据、贡献和评审，不能由协议保证。

Bug、依赖失效、数据哈希不一致或不满足结构划分最低条件，属于必须透明记录的技术/协议异常。修复时新建 amendment 版本，说明发现时间、是否已看过测试结果、影响哪些运行；不覆盖已封存对象。预定的否定结果不是必须重做方案的理由，真实错误也不能为了“无需改方案”而隐瞒。
