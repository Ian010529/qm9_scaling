# QM9 Scaling Law：完整实验方案

版本：v1.0；日期：2026-09-07；基线提交：`fdd0a611e486f25e5c4ccd8c148db9f5a6b782d2`。

## 0. 本次完善的边界

目标保持为**发现、刻画和验证分子性质预测中的 scaling law（规模定律）**，不是将课题改成普通模型排行榜，也不删减原来的三条路线、四个性质、八个训练规模和五次重复。

本文是实验设计，不代表所列训练器、分析脚本或实验结果已经存在。本次仅补充方案及修改报告，不修改训练代码、现有配置、数据、特征和划分。现有仓库已经准备三类输入并保存一次 XGBoost pilot；正式实验仍需按本文落实相应训练和分析功能。

本方案把调参、主实验、机制对照、外推检验、异常处理和论文产物事先约定，尽量避免取得结果后才决定补什么。方案完整不能保证一定观察到幂律或论文被接收；当数据不支持某一规律时，按预定规则报告适用区间、替代规律或失败证据，不为得到正结果重新设计实验。

## 1. 研究问题、假设与预期贡献

### 1.1 核心问题

在训练数据规模 N 增长时，Morgan＋XGBoost、从头训练的 D-MPNN、冻结 MoLFormer＋MLP 的预测误差是否遵循可预测的尺度关系？这种关系的指数、平台、交叉点及适用范围，如何受到目标性质、表示方式、模型容量和训练充分性的影响？

保留并同时回答以下问题：

| 编号 | 研究问题 | 主要证据 |
|---|---|---|
| RQ1 | 是否存在稳定的误差—数据规模关系？何种函数最能描述和预测它？ | 八规模学习曲线、候选函数比较、保留大规模点的外推检验 |
| RQ2 | 三条路线的指数、可达到误差和数据效率是否不同，是否存在交叉规模？ | 配对曲线、指数区间、目标误差对应样本量、交叉区间 |
| RQ3 | 不同性质，尤其 G 的组成效应，是否改变规模行为？ | 四性质对照、原子组成基线、G 残差全规模曲线 |
| RQ4 | 曲线平台或优势来自表示信息、模型容量，还是优化不足？ | count 指纹、预测头、容量和训练预算对照 |
| RQ5 | 规律对随机性及结构划分是否稳健？ | 子集×初始化交叉重复、骨架划分补充实验 |

预登记的方向性假设是：增加 N 会降低误差；不同路线和性质具有不同的有效指数与平台；表示及组成处理可能改变这些参数。**不预设哪条路线一定获胜，不预设所有性质共享一个指数，也不预设一定存在交叉点。**

### 1.2 与已有研究的关系

分子表示学习的规模行为已有直接研究，[R2]讨论了模态、划分、预训练和容量；2026 年的分子语言模型研究[R4]也涉及模型规模、训练数据和表示。因此不将“首次发现分子领域存在 scaling law”作为未经验证的新颖性声明。

本课题拟形成的证据链是：统一数据与输入信息 → 三路线多性质规模曲线 → 未参与定律拟合的大规模预测验证 → 表示/组成/容量/训练对照解释规律 → 结构划分与随机性检验。最终贡献陈述依据实际结果，不通过删减研究目标规避比较。

## 3. 原有主实验：完全保留

固定随机划分种子 20260905。训练池 104,595，验证集 13,075，测试集 13,074。

训练规模：`500, 1000, 2000, 5000, 10000, 20000, 50000, 100000`。

| 重复编号 | 子集种子 | 训练种子 |
|---|---:|---:|
| 1 | 11 | 101 |
| 2 | 22 | 102 |
| 3 | 33 | 103 |
| 4 | 44 | 104 |
| 5 | 55 | 105 |

每个子集种子只生成一条训练池排列，D_N 为前 N 个 ID；三条路线、四个性质共用相同 ID。每个 N 从头训练一个模型，不将小规模 checkpoint 接着训练到大规模，也不把五个模型集成后当成单次结果。

主实验总量：`3 × 4 × 8 × 5 = 480` 次正式训练。

这里 N 表示当前模型拟合使用的训练标签数，不表示项目总标注成本。固定验证集、下文锚点调参使用的标签也属于可用开发信息，必须分别报告。它们不被偷偷计入 N，也不声称这是“总共只有 N 个标签”的预算实验。

## 4. 调参协议：先选择配置，再固定配置研究 N

### 4.1 开发与正式训练分离

每个“路线×目标×划分协议×目标处理方式”独立选配置。锚点规模固定为 2k 和 20k；从对应训练池生成子集种子 71、72，训练种子为 701、702。新开发序列单独保存，不覆盖五条正式序列。

每个候选配置运行两规模×两重复。评分为四次验证 MAE 与各自训练中位数基线验证 MAE 的比值的几何平均；分母最低取 1e-12。配置选择不读取测试结果。评分差不超过最优值的 1% 时，依次选择参数更少/深度更浅、训练耗时更低、配置编号更小的候选。

每一组确定一个配置，随后在八个 N 和五个正式种子上保持不变。正式实验中仍可按同一早停规则选择 checkpoint。需要不同规模分别调参时，应另标为“调优包络”，不能混入固定配置主曲线；本版不依赖该额外实验得到主要结论。

锚点包含 20k 数据，意味着小规模结果是在经过锚点开发的学习系统下得到，不宣称具有严格的 N 标签总预算。这一披露与第3节一致。

### 4.2 搜索空间与固定参数

| 路线 | 八个候选的笛卡尔积 | 其余固定设置 |
|---|---|---|
| binary/count Morgan＋XGBoost | max_depth∈{4,8}；learning_rate∈{0.03,0.10}；reg_lambda∈{1,10} | subsample=0.8，colsample_bytree=0.8，min_child_weight=1，reg_alpha=0，hist，squarederror |
| D-MPNN | hidden∈{256,512}；lr∈{0.0003,0.001}；dropout∈{0,0.1} | depth=3；FFN 两个隐藏层、宽度同 hidden；mu/homo/lumo 用 mean 聚合，G 用 sum 聚合 |
| MoLFormer/Morgan＋MLP | hidden∈{256,512}；lr∈{0.0003,0.001}；dropout∈{0,0.1} | 两个等宽隐藏层、ReLU、无 BatchNorm、线性单输出 |
| MoLFormer＋Ridge | lambda=10^k，k=-6,-5,…,1 | 目标函数 mean squared error + lambda×系数平方和；不惩罚截距；记录库参数的等价换算 |

Ridge、count、Morgan＋MLP 在同样锚点独立选择配置。G 残差路线独立调参；D-MPNN 残差仍用 sum 聚合，使“直接/残差”比较不同时改变聚合方式。骨架协议也只使用自己的训练/验证数据独立调参，不借用在另一协议标签上选出的最优配置。

### 4.3 训练预算及预处理

XGBoost：最多 6000 棵树，验证 MAE 早停耐心 300；预测使用最佳迭代。原有 2000 棵树配置继续保留为历史 pilot，不作为正式搜索结论。

神经网络：AdamW，weight_decay=1e-4，有效 batch size=64，梯度范数裁剪=5，最多 500 epochs。每 epoch 计算完整验证 MAE；至少完成 50 epochs 且 2000 次更新后才允许早停；早停耐心 80 epochs。ReduceLROnPlateau 监测标准化目标尺度下验证 MAE，factor=0.5、patience=20、min_lr=1e-6、threshold=1e-5、threshold_mode=absolute；早停的改善阈值同为 1e-5。保存并恢复验证 MAE 最优 checkpoint。损失均为标准化目标的 MSE，评价用原单位 MAE/RMSE。

每次训练的目标均值和标准差只拟合当前 D_N。MoLFormer 输入按特征维度在 D_N 上标准化；Morgan binary 保留0/1，count 直接输入树，Morgan＋MLP 保留0/1。标准差为0的维度用 scale=1。Ridge 也使用本次 D_N 的输入/目标标准化。

保存 train/validation 曲线、最佳 epoch/iteration、实际更新数、参数量、学习率历史、训练时间和峰值内存。训练集 MAE 在最佳 checkpoint、eval 模式计算，不能拿训练过程的平均 minibatch loss 代替。

| A：表示/预测器 | count Morgan＋XGB、binary Morgan＋MLP、MoLFormer＋Ridge；4性质×3规模×3重复 | 108 | 二进制信息损失、预测头影响 |

A中 count 固定为半径2、2048维的真实环境计数，不用 count-simulated bits，不根据测试结果选择其他半径或位数。A仅有三规模点，不据此估计三参数饱和幂律的可靠指数；主要报告相对主路线的配对误差改善。

C中 D-MPNN 的消息宽度和FFN宽度均翻倍，MLP隐藏宽度翻倍，XGBoost最大深度增加2；其他超参数与所选主配置相同，不重新调参。D中神经网络上限翻倍至1000 epochs、最低训练要求和早停耐心翻倍，XGBoost树上限12000、早停耐心600；其他设置不变。C/D是分别改变一个因素的诊断，不将两者同时改变。

### 5.1 原子组成基线与 G 残差

从SMILES计数 H/C/N/O/F，H包括隐式氢。对每个 D_N 独立用最小二乘拟合带截距的组成基线：

`G_comp = b + w_H n_H + w_C n_C + w_N n_N + w_O n_O + w_F n_F`。

采用float64、SVD求解，奇异值相对阈值1e-12；列秩不足时使用该阈值下的最小范数解并记录秩。基线系数不解释为严格的孤立原子自由能。

训练残差 `delta_G = G - G_comp`。验证和测试的G_comp使用该D_N拟合的系数，绝不能在全量数据上拟合。三路线在同一D_N共用组成基线；最终预测还原为 `G_hat = G_comp + delta_G_hat`，在原G单位计算指标并形成八规模曲线。各D_N的基线会变化，故解释为完整残差学习流程的规模行为，不能把不同N的残差标签当成同一固定任务的不可约误差。

所有目标均报告训练均值、训练中位数基线；G额外报告组成基线。基线拟合不计入上述神经/树模型次数，但耗时和误差必须保存。

### 5.2 结构划分的确定规则

保留随机划分为主实验，同时新增独立结构划分，不覆盖旧splits。使用RDKit Bemis–Murcko骨架、无立体标记；同一骨架不可跨训练池/验证/测试。所有空骨架归为同一组，不把无环分子逐个随机拆散冒充骨架外推。

目标比例80/10/10。骨架组按成员数降序处理，同大小组用种子20260906生成的固定顺序打破平局；每组依次分配到“加入该组后，三个分区相对目标数量的平方偏差总和最小”的分区，平局按pool、val、test次序处理。生成后检查训练池至少50k，验证/测试各至少1k，且骨架互斥。数量不足时按相同规则、种子20260907至20260925重试；只按数量偏差选择满足约束的划分，不查看标签或模型分数。全部失败则如实报告该骨架协议的可行性失败，不默默替换成随机划分。

在确定的骨架训练池内建立子集种子11/22/33的嵌套序列，训练种子101/102/103。单独记录空骨架组位置、最大组大小、比例偏差、各划分骨架数、重原子分布及训练—测试结构相似性摘要。

该包有三个N，因此主要检验趋势和路线排序的迁移，不把它包装成与八规模主实验同等强度的指数识别。不同划分协议独立完成调参、冻结和评价；不得查看另一协议的测试表现后修改本协议的候选空间。

## 6. Scaling law 的拟合与验证

### 6.1 量的定义与拟合尺度

对路线m、性质t、重复r，令E_m,t,r(N)为最佳checkpoint的原单位测试MAE。主分析拟合五次重复的平均MAE曲线；同时展示五条原始曲线，不能只展示拟合线。RMSE重复同样流程作为稳健性分析，不能看到结果后替换主指标。

误差以该曲线N=500的平均MAE归一化用于数值求解，最终恢复原单位；N用x=N/1000。每个规模在目标函数中等权，最小化log误差残差平方和。不把五种子×八规模当作40个独立规模点。

候选族固定为：

| 候选 | 函数 | 作用 |
|---|---|---|
| 常数 | E=c | 无数据增长收益的对照 |
| 纯幂律 | E=A x^(-alpha) | 无平台项的规模定律 |
| 饱和幂律 | E=E_inf+A x^(-alpha) | 带经验平台的规模定律 |
| 饱和指数 | E=E_inf+A exp(-x/tau) | 非幂律的替代缩放规律 |

约束：A≥0、c>0、E_inf≥0、alpha∈[0.001,5]、tau∈[0.001,10000]；E_inf不超过拟合区间观测平均误差的最小值。求解使用固定多起点：alpha起点{0.1,0.3,0.7,1.5,3}，平台起点为最小误差的{0,0.25,0.75}，tau起点{0.1,1,10,100}；各起点的A用最小N点初始化；保留收敛且损失最低解。所有失败及触边均记录，不把参数触边解释成发现物理常数。

### 6.2 真正的大规模外推检验

先完成并冻结神经/树模型的训练协议。规模定律开发仅使用前六个N：500至20k；50k和100k作为**规模层面的保留验证点**。

在前六点内使用滚动外推：以前四点预测10k，以前五点预测20k。候选族按两次平均绝对log预测误差选择；分数距最优不超过5%时选择参数更少的族，同参数数目依次优先饱和幂律、饱和指数。之后用前六点重拟合选定族，保存候选、参数、50k/100k点预测及不确定性，生成带哈希的预测登记文件，再揭示两点的实际测试MAE。

分子层测试集用于测量已冻结分子模型的泛化误差；其前六规模的误差随后是定律拟合数据。不能将这六点同时宣称为定律的独立验证。独立性来自50k/100k误差没有参与函数选择及拟合，不是因为它们使用了另一批测试分子。

报告两点的绝对及相对外推误差、预测带覆盖情况，并与“保持20k误差不变”的外推基线比较。全八点最终重拟合只用于更精确的参数描述，不能覆盖之前登记的外推预测或替代其得分。

### 6.3 结果分类标准

以下阈值是本研究预设的工程判据，不是通用统计定理：

- 若幂律族在开发选择中胜出，两个保留点平均相对预测误差≤10%，且优于保持20k不变基线，则记为“通过本协议的幂律外推检验”。同时逐点报告，不能用平均值隐藏其中一个严重失败点。
- 若指数族或常数族胜出，如实报告替代关系或缺乏增长证据；不改候选族直到幂律获胜。
- 若曲线拟合好但外推失败，记为“区间内拟合成立、外推未通过”。
- 若饱和幂律的alpha或E_inf不稳定、频繁触边，则报告可预测性与参数不可识别并存；不据此解释“不可约误差”。

“得到一条幂律曲线”和“发现具有独立预测能力的规律”分别报告。研究目标仍是发现scaling law，判断标准用于判断证据，而不是提前取消这一目标。

### 6.4 分段、局部指数和交叉点

预先保留分段规律作为次级分析：对全八点拟合连续两段幂律，断点仅允许5k或10k，断点两侧各至少三个规模。函数为 `E=A x^(-alpha1) max(1,N/Nb)^(alpha1-alpha2)`，使用同样log损失和alpha边界；无平台项以控制自由度。报告两个断点候选，不将全八点选择出的分段规律追认成已通过第6.2节检验。

局部指数为相邻点的 `-delta log(E)/delta log(N)`，报告原始总误差与饱和幂律alpha的区别：有平台时二者并不等价。

模型交叉点仅在[500,100000]内求解，并要求实测邻近规模存在相应排序变化；报告bootstrap交叉点范围和无交叉比例。没有观测支持时写“观测区间内未确认”，不外推一个精确N值。若出现多次交叉，全部报告。

目标误差对应样本量固定用各性质训练中位数基线误差的{0.75,0.5,0.25}作为参考；基线值取主训练池前20k、子集种子11所得到的验证误差，配置冻结时记录。逆解只在已验证的曲线区间内使用，未达到的阈值标为未达到。

## 7. 统计、不确定性与解释性分析

保持三个模型和四个目标在相同重复编号上的配对。主结果给出全部重复值、均值、标准差；误差棒注明描述的是联合子集/初始化变动，不能称为五次独立数据划分的波动。

使用2000次bootstrap，随机种子20260908：每次抽样一个完整重复编号序列，使同一编号下所有N、模型和性质的对应关系一起保留；定律拟合和模型差异都在每次重采样内重算。不能将嵌套序列上的单个点随意打散。

分别报告两类区间：①重复层bootstrap，条件于固定训练池/测试集；②另加入测试分子有放回抽样的两层bootstrap，分子索引在全部模型/N间共享。第二类不是五个独立训练池的区间，也不能修正预训练重叠问题。骨架测试的分子不独立时，以完整骨架组替代单分子进行第二层抽样。

外推图显示参数不确定性带，同时明确其不自动等于含模型失配的预测区间。额外用开发滚动外推的最大绝对log残差向两侧扩张，形成预先定义的经验预测带；两个开发误差不能提供可靠的95%覆盖保证，故仅称经验带。报告其实际覆盖，不宣称具有理论校准保证。

对12条主曲线分别给出点态区间，并提供共享bootstrap下、按各曲线bootstrap标准差标准化的最大偏差同时区间，区分单曲线与整体结论。五个重复有限，不凭区间细微差异做精细排序；F提供额外随机性解释。主要证据是保留规模预测与效应量，不把样本量庞大的逐分子p值当作训练随机性证据。

误差分解固定按重原子数、元素组成、环数分组；组内至少100个测试分子才报告独立指标，其余合并为低计数组。给出G组成基线前后误差、相同指纹组内误差和训练/测试相似性分层，不根据结果临时挑选“好看的”分子案例。

## 8. 无需临时重拟方案的异常与补充规则

| 情况 | 预定处理 |
|---|---|
| 数据/ID/哈希/划分互斥失败 | 停止受影响运行；先修数据完整性问题，不将错误运行并入统计 |
| NaN、损坏checkpoint、环境异常 | 相同配置/种子最多重试两次；保留失败日志，不能换种子挑成功结果 |
| 显存不足 | 优先保持有效batch=64的微批次梯度累积；固定无BatchNorm；记录差异；仍失败则标记资源失败 |
| 最优checkpoint触及预算上限，或尾段仍改善 | 由D包先诊断；D在相应“路线×性质”的三个N中至少两个带来平均MAE≥2%改善时，对该组合全部八规模、五重复执行加倍预算；保留原曲线，新增充分训练曲线 |
| C包至少两个N改善≥2% | 对该路线×性质扩展完整八规模、五重复的大容量曲线；保留主结果，不静默替换模型 |
| alpha的95%区间宽度大于其点估计，或>10% bootstrap拟合触边/失败 | 该路线×性质增加子集种子66/77/88/99/110与训练种子106—110，所有八规模一起追加；原五次和合计十次均可追踪 |
| 50k/100k外推失败 | 原始失败结论保留；固定追加30k/40k/60k/80k、原五重复用于定位失配区间。追加数据形成次级规律分析，不能当作未见数据再次宣称验证成功 |
| 未出现交叉或明显平台 | 如实报告未观察到，不强制拟合交叉点，不因为缺少预想现象增加模型 |
| 骨架划分不满足数据量 | 按第5.2节的固定候选规则处理；不能根据测试分数选择骨架划分 |

这些是执行前规定的分支，不是看到结果后重新挑选研究方案。所有触发按三重复平均值计算；相应对照的新运行复用已完成且配置/种子完全一致的结果。新增次数单独汇总，不能继续把总预算称为480次。

扩展运行如发生在大规模测试结果已揭示之后，其新规律只能标为次级分析；不能通过改文件时间或重新登记来恢复失去的保留性。软件缺陷修复需记录影响范围并重跑受影响结果，不能承诺方案能预见所有实现错误。

## 9. 计算成本与任务量

基本正式拟合1248次。调参按每组8候选×2锚点×2重复计算：主路线12组=384；A三条对照×四性质=384；G残差三组=96；骨架主路线12组=384；共1248次调参拟合。因而计划基础总数为**2496次模型拟合**，另加廉价基线、实现自检、失败重试与第8节触发的扩展。这个数字不表示当前已经执行。

先在目标运行设备上测量代表性规模的真实时间/内存，再汇总资源预算；不在没有测量时承诺具体GPU小时。缺资源时分批执行既定矩阵，不默默删除不利结果或改变实验定义。

成本分开报告：原始数据/图/指纹准备，冻结MoLFormer提取，HPO，每次下游训练，最佳checkpoint推理。MoLFormer已发生的外部预训练成本未知，标记unknown；不能把复用向量的MLP训练成本说成整个预训练路线的总成本。

报告误差—训练标签数、误差—下游训练时间、误差—总已测开发成本三种图。跨硬件时间不直接解释为模型算法优势；记录CPU/GPU型号、线程数、库版本及精度。没有独立改变预训练模型/预训练数据规模时，不把下游学习曲线拟合成预训练计算最优定律。

## 10. 执行顺序与质量验收

### A. 实验前核验

确认现有数据/特征哈希、ID顺序、split互斥、嵌套性、单位、目标有限值及预处理训练集限定。检查图中零键分子可处理，模型保存/加载前后预测一致。各神经路线须在固定32个训练分子上做1000步过拟合诊断；该诊断只用于发现实现错误，不能根据测试表现调结构。

对每路线×四目标，以500个正式训练分子进行功能试运行，检查原单位还原、均值/中位数基线、G组成残差还原、早停和checkpoint。功能结果标记smoke，不计入正式矩阵，也不据此挑选正式随机种子。

这些是执行方的验收要求，不是本次已运行的测试。本次没有实现训练器，也没有执行上述诊断。

### B. 校准与冻结

执行第4节锚点HPO，生成配置快照、开发标签ID清单、预算、版本、候选得分及选择理由。在任何正式测试指标揭示前冻结全部主配置、对照配置、骨架配置和分析规则。

### C. 主实验与外推登记

训练主实验及G残差的八规模模型，按第6.2节仅开放前六点误差用于定律开发；大规模预测文件可先保存，但指标不进入定律拟合。将50k/100k的定律预测登记后再评价两点。即使技术上可以读取文件，也不得用它们改参数或函数族。

### D. 对照与解释

完成A—F；按第8节自动触发必要补充。每个包分别标注完成/失败/未运行状态和实际分母，禁止缺失结果当零或静默丢弃。

### E. 结果汇总与写作

从逐分子预测重新计算汇总表，核对与各run指标一致；从登记文件重算外推得分；按第11节生成主文和补充材料。实验后不根据结果重写原假设或删除失败候选。
