# QM9 Scaling Law：完整实验方案

版本：v1.2；日期：2026-09-07；基线提交：`fdd0a611e486f25e5c4ccd8c148db9f5a6b782d2`。

## 0. 本次完善的边界

目标保持为**发现、刻画和验证分子性质预测中的 scaling law（规模定律）**，不是将课题改成普通模型排行榜，也不删减原来的三条路线、四个性质、八个训练规模和五次重复。

本文是实验设计，不代表所列训练器、分析脚本或实验结果已经存在。本次仅修改方案及报告，不修改训练代码、现有配置、数据、特征和划分。现有仓库已经准备三类输入并保存一次 XGBoost pilot；正式实验仍需按本文落实相应训练和分析功能。

v1.1保留原480次主实验、必要的模型选择、G组成基线及规模外推验证；将机制扩展、骨架实验和随机性分解改为有明确问题时选用，不作为统一的执行或投稿前置条件。保留现有章节结构和可复用的方法，不再要求完成全部扩展或因结果不理想自动追加实验。

v1.2仅明确核心研究问题、解释议题及其证据责任，区分必要的有效性检查与可选专项研究；不改v1.1的实验矩阵、训练设置、调参预算和分析方法。

方案完整不能保证一定观察到幂律或论文被接收；当数据不支持某一规律时，报告适用区间、替代规律或失败证据，不为得到正结果重新设计主实验。

## 1. 研究问题、假设与预期贡献

### 1.1 核心问题与解释议题

在统一的二维分子输入和QM9数据协议下，Morgan＋XGBoost、从头训练的D-MPNN、冻结MoLFormer＋MLP是否呈现不同但可预测的数据规模关系？较小规模实验能否预测较大规模下的误差、相对优势和样本需求？

RQ1—RQ3是主实验直接回答的核心问题；保留RQ4—RQ5作为针对观察结果的解释或扩展议题，不预先承诺本篇同时解决所有机制、随机性来源和结构泛化问题。

| 编号 | 研究问题 | 主要证据及执行位置 |
|---|---|---|
| RQ1（核心） | 误差如何随训练数据规模变化，所拟合关系能否预测保留的大规模点？ | 八规模、五次重复的学习曲线，候选函数比较及50k/100k预测检验 |
| RQ2（核心） | 三条完整路线的数据效率、可识别的规模参数和相对优势是否不同？ | 同一协议下的配对曲线、参数不确定性、样本需求及有观测支持的交叉区间 |
| RQ3（核心） | 四个性质呈现怎样的规模行为差异，G直接预测相对组成基线提供多少增益？ | 四性质曲线与G组成基线；基线比较本身不证明组成效应导致某个指数 |
| RQ4（解释议题） | 如何解释具体的平台或路线优势：表示、容量或优化是否有贡献？ | 先完成训练有效性检查；需要提出机制解释时，采用与该解释对应的对照，不全组合铺开 |
| RQ5（扩展议题） | 规律能否迁移到结构划分，或子集与初始化分别贡献多少波动？ | 相应的结构划分或随机性分解实验；核心五次重复仅描述联合随机波动 |

预登记的方向性假设是：增加N总体上会降低误差；不同路线和性质可能具有不同的有效规模行为。**不预设哪条路线一定获胜，不预设所有性质共享一个指数，也不预设一定存在平台或交叉点。** 表示或组成造成差异等机制解释，在有对应证据后提出，不作为主实验已识别的因果结论。

### 1.2 与已有研究的关系

分子表示学习的规模行为已有直接研究，[R2]讨论了模态、划分、预训练和容量；2026 年的分子语言模型研究[R4]也涉及模型规模、训练数据和表示。因此不将“首次发现分子领域存在 scaling law”作为未经验证的新颖性声明。

本课题拟形成的核心证据链是：统一数据与输入信息 → 三路线多性质规模曲线 → 未参与定律拟合的大规模预测验证。针对要解释的具体现象，再选择对应的机制或稳健性对照；不以对照数量代替研究贡献。

借鉴已有研究时，按研究问题匹配控制变量和证据，而不是照搬其全部实验，也不以他人未开展某项实验来免除本研究主要结论所需的检查。固定一个条件不等于必须把它另外研究成一个扩展轴。

### 1.3 研究条件与结论归属

本研究估计的是`E_m,t(N | P)`：在数据版本、划分、二维输入及模型开发协议P给定时，路线m对性质t的误差如何随训练分子数N变化。主要扩展轴是下游训练数据量；预训练模型大小、预训练数据量和计算最优分配不在本次主实验中独立变化。

主实验直接支持当前QM9协议中的完整路线比较和规模预测。路线间的差异不单独识别架构或预训练的因果作用；四个性质提供性质维度的证据，不等于四个独立数据集；50k/100k检验的是训练规模外推，不等于新化学分布泛化。提出更进一步的机制或迁移结论时，再提供相应对照。

实现正确和训练有效是解释主曲线的前提，不是可选研究。检查某个模型是否明显未训练充分，与系统研究所有模型的容量或优化预算如何扩展，是不同任务。前者须排查，后者仅在研究该因素时展开，不把尚未排除的明显训练缺陷包装成数据增长的极限。

## 4. 调参协议：先选择配置，再固定配置研究 N

### 4.1 开发与正式训练分离

基础调参仅覆盖三条主路线×四个目标，共12组，不预先为所有可选对照建立独立搜索任务。保留2k和20k两个锚点；使用一组固定开发子集种子71、训练种子701。开发序列单独保存，不覆盖五条正式序列。

每组保留下表八个候选，每个候选运行两规模×一次开发训练。评分为两次验证 MAE 与各自训练中位数基线验证 MAE 的比值的几何平均；分母最低取1e-12。配置选择不读取测试结果。评分差不超过最优值的1%时，依次选择参数更少/深度更浅、训练耗时更低、配置编号更小的候选。基础调参为`12 × 8 × 2 × 1 = 192`次拟合；五次正式重复仍完整保留，不用单次开发结果声称配置最优或消除了种子敏感性。

每一组确定一个配置，随后在八个 N 和五个正式种子上保持不变。正式实验中仍可按同一早停规则选择 checkpoint。需要不同规模分别调参时，应另标为“调优包络”，不能混入固定配置主曲线；本版不依赖该额外实验得到主要结论。

锚点包含20k数据，意味着小规模结果是在经过锚点开发的学习系统下得到，不宣称具有严格的N标签总预算。这一披露与第3节一致。调参预算是本项目的执行选择，不是投稿要求或公平比较的通用标准。

### 4.2 搜索空间与固定参数

| 路线 | 八个候选的笛卡尔积 | 其余固定设置 |
|---|---|---|
| binary Morgan＋XGBoost | max_depth∈{4,8}；learning_rate∈{0.03,0.10}；reg_lambda∈{1,10} | subsample=0.8，colsample_bytree=0.8，min_child_weight=1，reg_alpha=0，hist，squarederror |
| D-MPNN | hidden∈{256,512}；lr∈{0.0003,0.001}；dropout∈{0,0.1} | depth=3；FFN 两个隐藏层、宽度同 hidden；mu/homo/lumo 用 mean 聚合，G 用 sum 聚合 |
| MoLFormer＋MLP | hidden∈{256,512}；lr∈{0.0003,0.001}；dropout∈{0,0.1} | 两个等宽隐藏层、ReLU、无 BatchNorm、线性单输出 |

可选对照不自动复制本节完整调参矩阵。单因素诊断保留其他设置不变；若要比较某个新增路线充分调优后的性能，再单独登记开发预算并仅使用允许的训练/验证数据选配置。尤其不能将另一划分协议中包含本协议测试分子的开发标签用于本协议的选模。

### 4.3 训练预算及预处理

XGBoost：最多6000棵树，验证MAE早停耐心300；预测使用最佳迭代。原有2000棵树配置继续保留为历史pilot，不作为正式搜索结论。

神经网络：AdamW，weight_decay=1e-4，有效batch size=64，梯度范数裁剪=5，最多500 epochs。每epoch计算完整验证MAE，早停耐心80 epochs；**不再叠加“至少50 epochs且2000次更新”的最低训练门槛**。ReduceLROnPlateau监测标准化目标尺度下验证MAE，factor=0.5、patience=20、min_lr=1e-6、threshold=1e-5、threshold_mode=absolute；早停的改善阈值同为1e-5。保存并恢复验证MAE最优checkpoint。损失均为标准化目标的MSE，评价用原单位MAE/RMSE。

这些是开发阶段的起始训练设置，不是已验证的最优配置。根据开发训练的学习历史检查早停、学习率和训练上限是否合理；若触及上限或仍持续改善，仅对受影响路线做预算检查，并在开放正式测试结果前记录、统一确定最终规则。不把500 epochs当成每次必须训练满的次数，也不机械要求所有路线做加倍预算实验。

每次训练的目标均值和标准差只拟合当前D_N。MoLFormer输入按特征维度在D_N上标准化；Morgan binary保留0/1。标准差为0的维度用scale=1。可选count指纹直接输入树；可选Morgan＋MLP保留0/1；可选Ridge使用当前D_N的输入/目标标准化。

保存train/validation曲线、最佳epoch/iteration、实际更新数、参数量、学习率历史、训练时间和峰值内存。训练集MAE在最佳checkpoint、eval模式计算，不能拿训练过程的平均minibatch loss代替。

## 5. 必要基线与可选针对性对照

**基础计划只要求原480次主实验及第5.1节的廉价基线；下表A—F不是默认必做矩阵。** 只有对应问题确实需要额外证据时，才选择相关路线、性质和规模执行，并事先记录该次对照的问题、配置和预算。没有开展的可选实验标记未开展，不虚构对应结论，也不将它们列为未完成的核心任务。

此处“可选”针对专项研究的展开范围，不豁免第4、8、10节的有效性检查。对照一旦成为主要机制或泛化论断的证据，就须完成相应核验，或不作该专项论断；不为没有提出的主张追加整套实验。

| 对照 | 何时有必要 | 采用时的设置建议，不要求全组合 |
|---|---|---|
| A：表示/预测器 | 要判断binary指纹的信息损失，或区分预测头与输入表示的作用 | 在count Morgan＋XGB、binary Morgan＋MLP、MoLFormer＋Ridge中选择与问题直接相关的一项；相关目标的1k/10k/100k，优先复用前三组主实验配对 |
| B：G残差学习 | G组成基线不足以解释观察到的差异，且论文需要讨论组成之外的规模行为 | 对需要比较的路线采用第5.1节残差流程；若需要残差曲线的指数，再做八规模和五重复，不默认三路线全部增加 |
| C：容量诊断 | 准备将平台解释为容量限制，或学习历史提示容量可能不足 | 仅对相关路线/目标在代表性规模增加容量，其他设置不变 |
| D：训练充分性 | 开发学习历史触及预算上限或未充分收敛 | 先对受影响配置检查增加预算的效果，不安排所有路线×目标的加倍训练矩阵 |
| E：结构划分 | 论文需要结构泛化或划分稳健性结论 | 采用第5.2节独立骨架协议，选择相关目标及代表性规模 |
| F：随机性来源 | 论文确实需要区分子集与初始化波动，而非仅报告联合重复稳定性 | 仅对相关组合开展子集×初始化交叉设计；取消默认新增216次运行 |

采用A时，count固定为半径2、2048维的计数指纹，不用count-simulated bits，不根据测试结果选择其他半径或位数；哈希后的计数仍不等于无碰撞结构表示。三个规模的对照主要报告配对改善，不据此估计可靠的三参数饱和幂律。可选Ridge的开发候选为lambda=10^k，k=-6至1；目标为mean squared error + lambda×系数平方和，不惩罚截距并记录库参数换算，仅在启用该对照时执行。

采用C时，可保留原诊断设置：D-MPNN消息/FFN宽度或MLP隐藏宽度翻倍，XGBoost最大深度增加2；其余参数不变。采用D时，可将神经网络训练上限和早停耐心、XGBoost树上限和耐心翻倍；不同时改容量。对照结果仅解释所改变的因素，不自动扩展整条曲线。

采用F时，保留真正的3×3交叉设计，而非把原来的五个配对种子误称为随机性分解；已有配置和种子完全一致的主实验结果直接复用。三个水平不足以支持过度精确的方差分量解释。

### 5.1 原子组成基线与可选 G 残差

从SMILES计数H/C/N/O/F，H包括隐式氢。对每个D_N独立用最小二乘拟合带截距的组成基线：

`G_comp = b + w_H n_H + w_C n_C + w_N n_N + w_O n_O + w_F n_F`。

采用float64、SVD求解，奇异值相对阈值1e-12；列秩不足时使用该阈值下的最小范数解并记录秩。基线系数不解释为严格的孤立原子自由能。

三条路线在同一D_N共用组成基线，共八规模×五子集=40次廉价线性拟合；验证和测试使用该D_N拟合的系数，绝不能在全量数据上拟合。所有目标均报告训练均值、训练中位数基线；G额外报告组成基线。基线耗时和原单位误差必须保存。

该比较回答“组成信息能预测到什么程度，以及完整路线比这一基线改善多少”；仅凭基线不能认定组成效应造成了某个规模指数。需要解释组成之外的行为时，再启用下面的残差对照。

**仅在启用B时**训练残差`delta_G = G - G_comp`；最终预测还原为`G_hat = G_comp + delta_G_hat`，在原G单位计算指标。直接预测G的主实验不替换。残差D-MPNN仍使用sum聚合，使直接/残差比较不同时改变聚合方式。各D_N的基线会变化，故解释为完整残差学习流程的规模行为，不能把不同N的残差标签当成同一固定任务的不可约误差。

### 5.2 可选结构划分的确定规则

本节只在启用E时执行，不是启动主实验的条件，也不覆盖旧splits。使用RDKit Bemis–Murcko骨架、无立体标记；同一骨架不可跨训练池/验证/测试。所有空骨架归为同一组，不把无环分子逐个随机拆散冒充骨架外推。

目标比例80/10/10。骨架组按成员数降序处理，同大小组用种子20260906生成的固定顺序打破平局；每组依次分配到“加入该组后，三个分区相对目标数量的平方偏差总和最小”的分区，平局按pool、val、test次序处理。生成后检查训练池至少50k，验证/测试各至少1k，且骨架互斥。数量不足时按相同规则、种子20260907至20260925重试；只按数量偏差选择满足约束的划分，不查看标签或模型分数。全部失败则如实报告该骨架协议的可行性失败，不默默替换成随机划分。

在确定的骨架训练池内建立子集种子11/22/33的嵌套序列，训练种子101/102/103；代表性规模可用1k/10k/50k，仅选择与结构泛化主张相关的路线和目标。单独记录空骨架组位置、最大组大小、比例偏差、各划分骨架数、重原子分布及训练—测试结构相似性摘要。

三个N主要检验趋势和路线排序的迁移，不包装成与八规模主实验同等强度的指数识别。使用本协议自己的训练/验证数据选模并记录预算，不自动要求完整的独立八配置搜索；不得用另一协议中暴露过的本协议测试标签选配置。若相关测试标签已经用于先前研究决策，则明确标注为次级探索验证，不追认为独立确认实验。

## 6. Scaling law 的拟合与验证

### 6.1 量的定义与拟合尺度

对路线m、性质t、重复r，令E_m,t,r(N)为最佳checkpoint的原单位测试MAE。主分析拟合五次重复的平均MAE曲线；同时展示五条原始曲线，不能只展示拟合线。RMSE重复同样流程作为稳健性分析，不能看到结果后替换主指标。

误差以该曲线N=500的平均MAE归一化用于数值求解，最终恢复原单位；N用x=N/1000。每个规模在目标函数中等权，最小化log误差残差平方和。不把五种子×八规模当作40个独立规模点。

候选族固定为：

| 候选 | 函数 | 作用 |
|---|---|---|
| 常数 | E=c | 无数据增长收益的对照 |
| 纯幂律 | E=A x^(-alpha) | 无平台项的规模定律 |
| 饱和幂律 | E=E_inf+A x^(-alpha) | 带经验平台的规模定律 |
| 饱和指数 | E=E_inf+A exp(-x/tau) | 非幂律的替代缩放规律 |

约束：A≥0、c>0、E_inf≥0、alpha∈[0.001,5]、tau∈[0.001,10000]；E_inf不超过拟合区间观测平均误差的最小值。求解使用固定多起点：alpha起点{0.1,0.3,0.7,1.5,3}，平台起点为最小误差的{0,0.25,0.75}，tau起点{0.1,1,10,100}；各起点的A用最小N点初始化；保留收敛且损失最低解。所有失败及触边均记录，不把参数触边解释成发现物理常数。这些后处理不新增分子模型训练。

### 6.2 真正的大规模外推检验

先完成并冻结神经/树模型的训练协议。规模定律开发仅使用前六个N：500至20k；50k和100k作为**规模层面的保留验证点**。它们已经包含在原480次主实验中，不新增训练任务。

在前六点内使用滚动外推：以前四点预测10k，以前五点预测20k。候选族按两次平均绝对log预测误差选择；分数距最优不超过5%时选择参数更少的族，同参数数目依次优先饱和幂律、饱和指数。之后用前六点重拟合选定族，保存候选、参数、50k/100k点预测及不确定性，生成带哈希的预测登记文件，再揭示两点的实际测试MAE。

分子层测试集用于测量已冻结分子模型的泛化误差；其前六规模的误差随后是定律拟合数据。不能将这六点同时宣称为定律的独立验证。保留性来自50k/100k误差没有参与函数选择及拟合，不是因为它们使用了另一批测试分子；共用测试分子和嵌套训练数据仍会产生相关性。

报告两点逐点及平均绝对/相对外推误差，并与“保持20k误差不变”的外推基线比较；第7节的参数不确定性带不冒充经校准的预测区间。全八点最终重拟合只用于参数描述，不能覆盖之前登记的外推预测或替代其得分。

### 6.3 结果解释

不再使用“平均相对误差≤10%即通过”的统一判定门槛，也不因超过该数值自动追加实验。主要证据是各候选的开发预测表现、两个保留点的实际误差、相对保持20k不变基线的改善，以及重复间波动。

幂律族在开发选择中胜出且在保留点表现出预测优势时，报告支持程度和适用区间；两点的表现分别呈现，不用均值隐藏其中一个失败点。若指数族或常数族胜出，如实报告替代关系或缺乏增长证据；不改候选族直到幂律获胜。若区间内拟合好但外推不佳，保留这一结论。若alpha或E_inf不稳定、频繁触边，报告参数不可识别，不将经验平台解释为物理不可约误差。

分别评价预测是否有用、函数族是否有支持、参数是否可识别。开发阶段只有六个规模点，多起点求解与bootstrap不增加规模信息；预测有用但指数或平台不稳定可以同时成立，不因此自动扩展实验来追求每个参数都精确。

“得到一条幂律拟合曲线”和“该关系能预测保留规模”分别报告。研究目标不变，结论由证据决定，不靠新增任务直到得到预想结果。

### 6.4 分段、局部指数和交叉点

分段规律仅作为**可选次级分析**，不属于基本交付要求。采用时保留原方法：对全八点拟合连续两段幂律，断点仅允许5k或10k，断点两侧各至少三个规模；函数为`E=A x^(-alpha1) max(1,N/Nb)^(alpha1-alpha2)`，使用同样log损失和alpha边界，无平台项。报告两个断点候选，不将全八点选择出的分段规律追认成已通过第6.2节检验。

局部指数为相邻点的`-delta log(E)/delta log(N)`，报告原始总误差与饱和幂律alpha的区别：有平台时二者并不等价。

模型交叉点仅在[500,100000]内求解，并要求实测邻近规模存在相应排序变化；报告bootstrap交叉点范围和无交叉比例。没有观测支持时写“观测区间内未确认”，不外推一个精确N值。若出现多次交叉，全部报告。

目标误差对应样本量用各性质训练中位数基线误差的{0.75,0.5,0.25}作为参考；基线值取主训练池前20k、子集种子11所得到的验证误差，配置冻结时记录。逆解只在获得预测支持的曲线区间内使用，未达到的阈值标为未达到；这些阈值不是定律成功/失败的判据。

## 7. 统计、不确定性与解释性分析

保持三个模型和四个目标在相同重复编号上的配对。主结果给出全部重复值、均值、标准差；误差棒注明描述的是联合子集/初始化变动，不能称为五次独立数据划分的波动。

保留2000次整条曲线bootstrap，随机种子20260908：每次对五个完整重复编号有放回抽样，使同一编号下所有N、模型和性质的对应关系一起保留；定律拟合和模型差异在每次重采样内重算，定律候选选择也按第6.2节在开发点内重做并报告选择频率。不能将嵌套序列上的单个点随意打散。报告关键参数和配对差异的百分位区间、拟合失败/触边比例；不同函数族的alpha不混成一个分布，某族很少被选中时不强行给出稳定指数。

基本区间条件于固定训练池和测试集，仅反映五次联合重复及拟合的不确定性；五次重复有限，bootstrap不会创造新的独立证据。外推图可显示参数不确定性带，但不宣称它具有包含模型失配的95%预测覆盖率。

不再默认要求测试分子/骨架层的两层bootstrap、12曲线同时区间或用两个滚动误差扩张经验预测带。只有另有明确的联合推断或测试集抽样问题时才增加相应方法。主要证据是保留规模预测和配对效应量，不把大量逐分子p值当作训练随机性证据。

G的组成基线比较保留。重原子数、元素组成、环数、相同指纹组或训练/测试相似性分层可作为针对性解释；采用时组内至少100个测试分子才报告独立指标，其余合并为低计数组。不根据结果临时挑选“好看的”分子案例。

## 8. 异常处理与补充实验原则

| 情况 | 处理 |
|---|---|
| 数据/ID/哈希/划分互斥失败 | 停止受影响运行；先修数据完整性问题，不将错误运行并入统计 |
| NaN、损坏checkpoint、环境异常 | 相同配置/种子最多重试两次；保留失败日志，不能换种子挑成功结果；持续失败时检查根因 |
| 显存不足 | 优先保持有效batch=64的微批次梯度累积；固定无BatchNorm；记录差异；仍失败则标记资源失败 |
| 开发训练触及上限或仍明显改善 | 检查受影响配置的训练预算；在正式测试开放前确定并记录规则，不机械对全部组合加倍训练 |
| 正式结果出现平台或疑似容量限制 | 先检查实现与学习历史，排查明显训练不足；需要机制解释时采用相关C/D，不用2%改善阈值自动扩展完整曲线，也不把未排除的训练缺陷当作数据极限 |
| alpha区间宽或拟合触边/失败 | 检查拟合和参数可识别性，报告不确定性；不默认再加五个种子，也不把不可识别直接当成重复不足 |
| 50k/100k外推不佳 | 如实报告失配；取消自动追加30k/40k/60k/80k；只有另有定位失配的明确问题时才开展次级实验 |
| 未出现交叉或明显平台 | 如实报告未观察到，不强制拟合交叉点，不因为缺少预想现象增加模型 |
| 可选骨架划分不满足数据量 | 按第5.2节处理并报告，不影响随机划分主实验的完成状态 |

任何新增对照须在执行前写明具体问题、范围、配置、预算及是否已接触相关测试结果；已有配置和种子完全一致的结果直接复用。不是必须把A—F全部做完，也不能静默丢弃已开展但不利的结果。

扩展运行如发生在大规模测试结果已揭示之后，其新规律只能标为次级分析；不能通过改文件时间或重新登记来恢复失去的保留性。软件缺陷修复需记录影响范围并重跑受影响结果；真实训练未充分时也不能将其误写为收敛后的规模规律。没有自动补跑不等于忽略实现错误或不利证据。

## 10. 执行顺序与质量验收

### A. 实验前核验
